            .map { |hour, contents_data| ... }

                前のステップで得られたハッシュの各キーと値のペアに対して処理を行い、結果を新しい配列として返します。

                hourは勉強時間（キー）、contents_dataはその時間に該当する課題の配列の配列（値）です。

                hour: hour:     
                    勉強時間。

                conut: contents_data.size: 
                    グループ内の要素数、つまり課題の数を取得します。

                contents: contents_data.map(&:first): 
                    contents_dataはまだ[["課題名", 勉強時間]]の形式なので、map(&:first)（またはmap { |s| s.first }）を使って、課題名だけを抽出した配列にします。

            .sort_by { |group| -group[:hour] }

                mapで変換された、目的の形式のハッシュの配列をソートします。

                sort_byは、ブロックの戻り値の昇順にソートします。

                降順にするために、ソートキーとして**group[:hour]にマイナスをつけた-group[:hour]**を指定しています。これにより、値が大きい（勉強時間が長い）ものほどマイナスの値が小さくなり、結果として降順でソートされます。
